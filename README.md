# MiniOvershields

Simple addon that shows overshields/absorbs on unit, player, and target frames.

This is mostly useful for:

- Disc priests to see how much their shields are over absorbing.
- Prot warriors for monitoring ignore pain.
- Mages for ice/blazing/prismatic barrier.

Works in Midnight.

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
